# Moshiur Rahamman Chowdhury — Professional Portfolio

Version 15.13 · Static GitHub Pages website

## Update an existing repository

1. Extract this ZIP. Open the existing GitHub portfolio repository and select the publishing branch (usually `main`).
2. Use **Add file → Upload files** to upload `index.html` and `contact.html` to the same directory as the current pages (normally the repository root). Replace the old files by committing the upload. Keep an existing `.nojekyll` file; if absent, add the empty `.nojekyll` included here. README.md is optional.
3. Commit with the message `Update portfolio to v15.13`.
4. Check **Actions** for the GitHub Pages deployment. If Pages is already configured, no settings changes are needed. For a new repository, go to Settings → Pages → Deploy from a branch → main → /(root), then Save.
5. Open the published site and refresh. Verify the navigation, two-line hero, theme selection, logo banner, mobile layout and contact link.

## Contact form

The existing FormSubmit integration is preserved. If not already activated, submit a test inquiry, confirm the activation email, and submit another test to verify delivery. The destination email address is visible in the public HTML. CAPTCHA is disabled; a honeypot provides basic spam mitigation only. Do not submit confidential data.

## Logo assets

The approved preview references external logo images, including third-party sources and some favicon fallbacks. Internet access is needed, and image providers may block hotlinking or change URLs. Not all logos are verified official assets; some requested organizations, including Rhode Island Department of State and Capital Hot Chicken, lack verified artwork. The Notre Dame College image may fail to load. No external images or email delivery were tested in preparing this archive.

The website is plain HTML/CSS/JavaScript; no build step is required.
