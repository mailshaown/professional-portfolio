# Professional portfolio

Static portfolio, version 15.3. Upload index.html, contact.html and .nojekyll to the root of a public GitHub repository. In Settings > Pages, select Deploy from a branch, main, / (root). Add your GitHub Pages hostname (USERNAME.github.io) to the existing Google reCAPTCHA key domain list. Test contact submission and confirm a Salesforce Case exists. The return URL is calculated from the deployed contact page. Do not commit reCAPTCHA secret keys or Salesforce credentials.
